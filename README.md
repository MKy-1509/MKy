# ⚡ IT Destek, Otomasyon & Yönetim Portalı

Kişisel portföy, dinamik CMS, blog altyapısı, ziyaretçi sayacı ve BT operasyonları için geliştirilmiş modern açık kaynaklı yönetim sistemi.

🔗 **Canlı Sistem:** [mevlutkaya.com.tr](https://mevlutkaya.com.tr)

### 🚀 Özellikler
- **Neo-Glassmorphism Tasarım:** Çoklu tema desteği (Cyan, Green, Amber) ve özel imleç/spotlight efektleri.
- **Döküman & Kurulum Portalı:** Sürücüler, kurulum setupları, YouTube video rehber entegrasyonu ve indirme takibi.
- **PDF Araçları:** Tarayıcı tabanlı hızlı araçlar ve dinamik sayfa yönetimi.
- **Güvenli Mimari:** PDO tabanlı SQL injection koruması ve KVKK uyumlu `ip_hash` sayaç sistemi.
